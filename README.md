ShelfDex
========

ShelfDex is a Windows game library and launcher with support for PC games
and configurable console emulators.

Supported platform categories
------------------------------
PC
PS1
PS2
PS3
Xbox
Xbox 360

Important
---------
ShelfDex is a launcher/library. It does not contain emulator binaries,
console BIOS/firmware, or game ROMs/ISOs.

Public distribution
-------------------
You can distribute the ShelfDex source freely.

Windows users do not need Python when using the built executable.

Emulator setup
--------------
Open ShelfDex -> Emulator Settings and select the emulator executable
installed on your computer.
